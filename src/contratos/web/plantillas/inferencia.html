Cómo intervino el modelo

Publicar solo lo que un modelo produjo da una impresión falsa de cuánto se apoya el sistema en él. El dato honesto es el embudo: cuántos documentos se resolvieron sin llamarlo.

Y dónde el modelo tampoco hizo falta, aunque se le llamó

Medido sobre las mismas fichas: cuando las causales vienen como lista enumerada —a) b) c)— un extractor de expresiones regulares devuelve exactamente las mismas que el modelo, en 0 s. El modelo solo gana cuando el documento las escribe en prosa corrida, donde el regex saca cero. Es la medición que decide dónde vale la pena y dónde no.
